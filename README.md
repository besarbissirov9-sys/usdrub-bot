# Бот «Курс Доллара | Новости USD/RUB»

Бот сам публикует в Telegram-канал:
- ⚡️ **уведомление о скачке доллара**, если курс (Мосбиржа, при недоступности ЦБ) изменился на 1 ₽ или 1% с прошлого уведомления;
- ☀️ **утреннюю сводку** раз в день после 9:00 по Москве: доллар, евро и юань по курсу ЦБ, изменение за день, курс Мосбиржи и нефть Brent;
- 📰 **новости** о долларе, рубле, ЦБ, ставке, нефти и санкциях из РБК, Интерфакса, Финама, Банки.ру, ПРАЙМ и Ведомостей (не больше 5 за запуск, без повторов).

Работает бесплатно на GitHub Actions: запускается каждые 20 минут.

## Пошаговая установка

### 1. Создайте репозиторий
1. Войдите на https://github.com (или зарегистрируйтесь бесплатно).
2. Справа вверху нажмите **«+» → New repository**.
3. Название: `usdrub-bot`. Выберите **Public** (для публичных репозиториев Actions бесплатны без лимита; в Private бесплатно 2000 минут в месяц, этого может не хватить при запуске каждые 20 минут).
4. Нажмите **Create repository**.

### 2. Загрузите файлы
1. Распакуйте архив `usdrub-bot.zip` на компьютере.
2. В репозитории нажмите **«uploading an existing file»** (или **Add file → Upload files**).
3. Перетащите **всё содержимое** папки: `bot.py`, `requirements.txt`, `README.md`, `state.json` и папку `.github`.
   ⚠️ Папка `.github` скрытая. На Windows включите «Показывать скрытые файлы», на Mac нажмите Cmd+Shift+. .
   Если папка не загружается, создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/bot.yml`, вставьте содержимое файла `bot.yml`.
4. Нажмите **Commit changes**.

### 3. Добавьте секреты (токен не должен лежать в файлах!)
1. В репозитории откройте **Settings → Secrets and variables → Actions**.
2. Нажмите **New repository secret**:
   - Name: `TELEGRAM_TOKEN`, Secret: токен бота от @BotFather.
3. Ещё раз **New repository secret**:
   - Name: `CHANNEL_ID`, Secret: `-1004463875620` (или `@dollar_rub_news`).

### 4. Разрешите боту сохранять состояние
**Settings → Actions → General → Workflow permissions** → выберите **Read and write permissions** → **Save**.
(Бот записывает в `state.json`, какие новости уже опубликованы, чтобы не повторяться.)

### 5. Запустите
1. Вкладка **Actions** → если просит, нажмите «I understand my workflows, go ahead and enable them».
2. Слева выберите **USD/RUB news bot** → **Run workflow** → **Run workflow**.
3. Через минуту появится зелёная галочка ✅, а в канале новые посты. Дальше бот работает сам.

## Полезно знать
- GitHub может запускать задания с опозданием на 5–15 минут, это нормально.
- Если в репозитории 60 дней нет изменений, GitHub отключает расписание. Бот сам коммитит `state.json`, поэтому обычно это не грозит; если отключилось — включите на вкладке Actions.
- Настройки (порог уведомления, число новостей, час сводки, ключевые слова, список источников) — в начале файла `bot.py`.
- Запуск на своём компьютере: `pip install -r requirements.txt`, затем `TELEGRAM_TOKEN=... CHANNEL_ID=... python bot.py`.
